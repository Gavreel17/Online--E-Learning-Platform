Create a complete, modern, responsive web-based system titled:

**“ONLINE E-LEARNING PLATFORM FOR STUDENTS”**

The system is an online learning platform where students can create an account, log in, view lessons and learning materials, take quizzes, and automatically see their scores and learning progress. The system must also have a separate Admin panel for managing students, lessons, quizzes, questions, and student results.

## 1. USER ROLES

Create two separate user roles:

### A. STUDENT

Students can:

* Register an account
* Log in and log out
* View their profile
* View available subjects/courses
* View lessons
* Read lesson content
* View uploaded learning materials
* Take quizzes
* Submit quiz answers
* Automatically calculate quiz scores
* View quiz results
* View previous quiz attempts
* Track learning progress
* View completed and incomplete lessons
* View their overall performance

### B. ADMIN

Admin has full access to the management system.

Admin can:

* Log in through a separate Admin login
* View Admin Dashboard
* Manage student accounts
* Add, edit, view, and delete student accounts
* Manage subjects/courses
* Add, edit, and delete lessons
* Upload learning materials
* Manage quizzes
* Add, edit, and delete quiz questions
* Set correct answers
* Set quiz passing scores
* View student quiz results
* View student performance
* View student progress
* Generate reports
* Manage Admin profile
* Log out

IMPORTANT:
Students must NOT be able to access the Admin Dashboard.
Only authorized Admin accounts can access administrative functions.
Use role-based authentication and route protection.

# 27. IMPORTANT SYSTEM BEHAVIOR

Implement these rules:

1. A student must register before logging in.
2. Students can only access Student pages.
3. Admin can only access Admin pages.
4. Students cannot create Admin accounts.
5. Admin can manage all learning content.
6. Students can only view lessons assigned/published by Admin.
7. Quiz scores must be calculated automatically.
8. Students cannot modify submitted quiz answers.
9. Quiz results must be saved in the database.
10. Student progress must update automatically when lessons are completed.
11. Quiz attempts must be recorded.
12. Admin can monitor student performance.
13. Prevent unauthorized access to protected routes.
14. Use real database operations instead of static/mock data.
15. All CRUD functions must work properly.
16. Search, filtering, validation, and confirmation dialogs should work properly.
